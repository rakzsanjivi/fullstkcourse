CSS Pseudo Classes

Pseudo-Classes: a:hover: Changes the link color to red when hovered. button:active: Changes the button background color to yellow when it is being clicked. input:focus: Adds a blue border to the input field when it is focused. li:nth-child(2): Changes the color of the second list item to green. li:not(:last-child): Adds a bottom margin to all list items except the last one. input:disabled: Changes the background color of disabled input fields to light grey. Pseudo-Elements: p :: first-line: Makes the first line of the paragraph bold. p :: first letter: Increases the size and changes the color of the first letter of the paragraph. p :: before: Adds "Note: " before the paragraph content. p :: after: Adds "[Read more]" after the paragraph content. :: selection: Changes the background and text color of selected text.
