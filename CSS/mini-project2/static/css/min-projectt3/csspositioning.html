Static : the Element is postioned accordint to the normal flow of the document



Stickyheadedr

Relative: The element is postioned relative to its normal position. Setting the top, right, bottom and left properties will cause it to be adjusted away from its normal position.



absolute: Completely removed from page flow; positions itself relative to its nearest positioned ancestor and moves with page scrolling.



fixed: Completely removed from page flow; locks itself relative to the browser viewport and never moves during scrolling.



sticky: Sits normally in the layout flow until scrolled to a specific threshold, where it pins itself until its parent container ends.
